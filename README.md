# Гриммуар Мрачного Гатца / The Grimoire of GrimGutz

Контент-модуль для Foundry Virtual Tabletop 14 и системы D&D5e 5.3.3.

Модуль добавляет авторские престиж-классы, трансформации, подклассы, заклинания, предметы и NPC/монстров для D&D 5e. Основной фокус — готовые compendium-карточки с Advancement, внутренними ссылками и автоматизацией там, где правило можно безопасно обработать через Foundry, D&D5e и Midi-QOL.

## Автоматизация

Изменения 0.15.1: [описание и ограничения](docs/AUTOMATION_0151.md), [реестр покрытия](docs/AUTOMATION_COVERAGE.md).

Автоматизированы:

- проверки требований для большинства престиж-классов, если GM включает их в настройках мира;
- выдача особенностей через D&D5e Advancement;
- пассивные эффекты, если у D&D5e есть стабильное поле для правила;
- ресурсы классов, трансформаций и отдельных особенностей;
- часть Midi-QOL хуков для урона, сопротивлений, временных эффектов и условных бонусов;
- безопасное обновление неизменённых карточек; ручные правки и неоднозначные старые документы сохраняются.

Не автоматизируются намеренно:

- правила, зависящие от решения Мастера;
- реактивные эффекты, где требуется выбор цели/момента вне стабильного hook-а;
- условные бонусы, которые невозможно отличить от более широкого правила без риска дать лишний бонус.

Основная автоматизация включена по умолчанию. Строгая проверка требований престиж-классов выключена по умолчанию; GM может включить её в настройках мира.

Площадные способности с шаблоном: нажмите активность → разместите область → Midi-QOL определит цели и проведёт спасброски → подтвердите бросок урона. Отмена размещения не тратит ресурс. Применение урона к хитам зависит от настроек Midi-QOL. [Поддерживаемые способности и добавление новых](docs/AREA_AUTOMATION.md).

Ауры автоматически создают круг, привязанный к токену: баффы/уязвимости применяются внутри и снимаются при выходе, урон и спасброски выполняются в указанный правилами момент. Для «Ауры резни» сначала выберите тип урона кнопкой карточки. [Поддерживаемые ауры и условия](docs/AURA_AUTOMATION.md).

Диагностика выбранного токена без изменения документов, в консоли Foundry:

```js
await game.modules.get("the-grimoire-of-grimgutz").api.inspectAutomation(canvas.tokens.controlled[0].actor)
```

После обновления полностью перезапустите Foundry и мир: канал призывов требует `socket: true`. Конфликты старых карточек видны в `items[].migration`; определения Advancement с уже сделанными выборами не заменяются автоматически.

Версия 0.15.0 добавляет повторный урон Вихря, стратагемы/присутствия Лидера, Кровопускание, высасывание, Метку/броню и антимагию Полого. Панель открывается через настройки модуля; события другой сцены ожидают подтверждения GM. [Использование, API и игровые проверки](docs/AUTOMATION_015.md).

## Разработка

Установка зависимостей:

```bash
npm install
```

Сборка compendium packs:

```bash
npm run build
```

Полная проверка:

```bash
npm run check
```

`npm run check` собирает packs и запускает валидатор иконок, количества документов, ссылок, Advancement, runtime-токенов и activity actions.

Для изменений только скриптов: `npm run verify` — поведенческие проверки и валидация без пересборки packs. [План аудита автоматизации](docs/AUTOMATION_AUDIT.md).

## Структура

- `src/packs/` — исходники compendium-документов.
- `scripts/automation/runtime.mjs` — общая регистрация Foundry hooks/API.
- `scripts/automation/classes/` — автоматизация отдельных престиж-классов.
- `scripts/automation/transformations/` — автоматизация трансформаций.
- `scripts/automation/subclasses/` — автоматизация подклассов.
- `scripts/automation/effects/` — синхронизация пассивных эффектов.
- `scripts/automation/midi/` — регистрация и организация Midi-QOL hooks.
- `scripts/automation/validation/` — проверки требований и Advancement.
- `tools/build-packs.mjs` — сборка compendium packs.
- `tools/validate.mjs` — локальная валидация модуля.

## Добавление нового контента

Используй flow-файлы:

- `docs/ADDING_PRESTIGE_CLASS.md`
- `docs/ADDING_TRANSFORMATION.md`
- `docs/ADDING_SUBCLASS.md`
- `docs/ADDING_NPC_ENEMY.md`

Правило структуры: карточки — в `src/packs/`, runtime-логика — в соответствующую подпапку `scripts/automation/`, проверки — в `tools/validate.mjs`.
