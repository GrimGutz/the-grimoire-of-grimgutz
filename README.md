# Гриммуар Мрачного Гатца / The Grimoire of GrimGutz

Модуль контента для Foundry Virtual Tabletop 14 и системы D&D5e 5.3.3.

## Содержимое версии 0.1.0

- престиж-класс **Сокрушитель**, рассчитанный на 5 уровней;
- автоматическая выдача классовых особенностей через Advancement;
- выбор одного из двух стилей огромного оружия;
- выбор трёх техник Сокрушителя на 2-м, 3-м и 5-м уровнях;
- автоматическое увеличение Силы на 4, максимум до 24, на 5-м уровне;
- пять образцов массивного оружия.

## Требования престиж-класса

- Сила 18;
- размер не ниже Среднего;
- черта «Мастер большого оружия»;
- 5-й уровень персонажа;
- найденное или выкованное массивное оружие.

Система D&D5e не проверяет эти нестандартные требования автоматически. Мастер должен проверить их перед добавлением класса персонажу.

## Разработка

```powershell
npm install
npm run check
```

Исходники документов находятся в `src/packs`. Команда `npm run build` пересобирает LevelDB-компендиумы в `packs`.

## Использование

1. Активируйте модуль в мире D&D5e.
2. Откройте компендиум **Престиж-классы**.
3. Перетащите класс **Сокрушитель** на персонажа, соответствующего требованиям.
4. При повышении уровня используйте стандартный менеджер развития D&D5e.
