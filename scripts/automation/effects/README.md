# Effect automation

Put reusable active-effect and passive-sync helpers here.

Current modules:

- `passive-helpers.mjs` — small shared Active Effect comparison helpers.
- `module-passives.mjs` — generic passive-effect sync from module items to owned actors.

Use this folder for code that:

- creates actor effects from item effects;
- synchronizes passive effects;
- normalizes Active Effect change paths between dnd5e versions;
- clears temporary combat effects.
