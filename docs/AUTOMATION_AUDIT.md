# План проверки автоматизации

Порядок: сначала поломки, затем ошибки правил, затем улучшения. Каждый законченный и проверенный блок — отдельный коммит. Push выполняется отдельным запросом.

- [x] Жизненный цикл временных эффектов: выделен общий модуль с полями Foundry 14, режимом удаления DAE и повторным запуском. Локальные поведенческие проверки пройдены; игровая проверка остаётся ниже.
- [x] Таймер не перезапускается при изменении имени/флага; вложенные и плоские обновления, а также обновления истечения DAE покрыты проверками.
- [x] Очистка включает синтетических актёров всех сцен, загрузку мира и игровое время; запись выполняет только активный GM.
- [x] Ауры: выключение очищает эффекты и границы; уход цели со сцены очищает связанного актёра; синхронизация выполняется последовательно, дубликаты удаляются. Повторное включение Пламени покрыто локальной проверкой.
- [ ] Призывы: валидные формулы и документы, создание токена, отсутствие второго призыва при двух клиентах, понятная обработка ошибки.
- [ ] Проверить импорт runtime, регистрации hooks и обработчиков действий, наличие реальных автоматизаций за описаниями карточек.

## Проверки и границы

- Исходная проверка `npm run validate`: успешно (29 классов, 421 особенность).
- Локальные проверки не заменяют проверку в работающем Foundry. Сценарии, которые требуют игровой сессии, отмечаются отдельно.
- Не затрагивать несвязанные пользовательские изменения и не коммитить служебные LOG-файлы LevelDB ради самого аудита.
- План обновляется фактами и результатами вместе с каждым исправлением; невыполненное не отмечается выполненным.

## Подтверждённые находки и проверка в игре

- Убраны невалидные единицы `minute/hour/day` из временных эффектов (Foundry 14 принимает множественные формы).
- Старый preUpdate перезапускал таймер на любом обновлении и мог отменять истечение эффекта; старый сборщик не учитывал синтетических актёров.
- Исправлено: ауры оставляли эффекты при выключении автоматизации и теряли дубликаты в Map. Четыре поведенческие проверки покрывают выключение, уход цели, параллельные вызовы и повторное включение.
- Исправлено: истёкшее Масло чёрной магии продолжало добавлять урон, оружейные баффы учитывали подавленные эффекты, Демоническая живучесть продолжала выдавать временные хиты. Обновление временных хитов Демонолога и Сосуда духа теперь выполняет один клиент.
- Исправлено: Сдвиг в сторону Мерцающего имел длительность «раунд + ход», хотя описание требует конец текущего хода. Теперь это отдельное событие `turnEnd`; до события бонус остаётся доступным.
- Общий helper длительности используется для оружейных баффов, состояний целей, Потока и Пламени исчадия. Наличие старого эффекта больше не означает наличие действующего бонуса.
- В Foundry после перезагрузки проверить: включить Пламя исчадия → продвинуть игровое время на 60 секунд → источник и граница исчезают; восстановить ресурс и включить снова. Повторить с несвязанным токеном. Изменение имени эффекта в середине минуты не продлевает длительность.
- Отдельно проверить эффекты до конца хода: удаление на нужном событии, без преждевременной очистки на чужом ходу.
