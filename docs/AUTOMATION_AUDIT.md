# Повторный аудит автоматизации Гримуара

## Итог реализации

Версия 0.14.26. Исходные 20 локальных сценариев расширены до 123; игровые проверки ниже остаются отдельным этапом. Добавлены [поток площадных способностей](AREA_AUTOMATION.md) и [привязанные к токенам ауры](AURA_AUTOMATION.md). В Midi передаются UUID Region, не сами документы. Ауры не расходуют ресурс активации повторно и не заканчивают эффекты следующего действия/попадания владельца при своих автоматических срабатываниях. Исправлено вмешательство синхронизации в нативную анимацию: один круг следует за токеном, конечные координаты берутся из сохранённых данных. Добавлены ответный урон Демонической живучести с нативным игнорированием сопротивления огню и преимущество союзникам на спасброски от смерти от Божественной преданности Крестоносца.

- [x] Сосуд духа: исправлен интерфейс выбора характеристики и урона, отмена не сохраняет выбор.
- [x] Призрачный странник: ресурс проверяется до списания; подтверждённый нативный расход не списывается повторно.
- [x] Зарегистрирован socket. Запросы обслуживает активный GM с проверкой отправителя и владельца; используется сцена игрока, не открытая сцена GM.
- [x] Групповой призыв подтверждается после создания всей группы. Подтверждённый частичный провал откатывает созданные этим запросом документы и расход; ошибка отката требует проверки GM.
- [x] Тайм-аут и унаследованный незавершённый запрос остаются pending, без повторного расхода, создания или предполагаемого возврата.
- [x] Дух странника существует минуту, духи Ритуалиста — десять минут или до 0 хитов. Потеря концентрации делает духов враждебными; есть изгнание и возвращение контроля с подтверждаемой СЛ.
- [x] Уникальные союзники обновляют управляемые значения, сохраняя урон, 0 хитов, ресурсы и ручные изменения. Старая форма без снимка не создаёт второго союзника.
- [x] Ползучий глаз: эффект владельца применяется в подтверждаемой транзакции призыва. Возвращение убирает токен и штраф; уничтоженный глаз требует решения Мастера о восстановлении.
- [x] Таймеры используют поля Foundry 14 и удаление DAE. Сохранение неизменённой формы не продлевает эффект; явное применение/изменение длительности/включение запускает новый срок.
- [x] Синтетические актёры всех сцен включены в загрузку и создание токенов. Ошибки актёра, пассива, спасброска или призыва не останавливают обработку остальных.
- [x] Критический порог Ведьминого клинка меняется через criticalSuccess и сохраняет более выгодный порог. Подавленные корни, истёкшая гвизарма и кулдаун не считаются активными. Печать без целей не тратит Гнев.
- [x] Ауры и зоны учитывают единицы, правила сетки и ближайшие занятые клетки токенов. Скрытые токены участвуют в механике; указатель скрытого источника скрыт, скрытые цели не перечисляются публично.
- [x] Очистка аур ограничена соответствующей сценой. Аура маскировки Полого даёт союзникам бонус ко всем спасброскам от Телосложения источника; действует сильнейшая такая аура.
- [x] Движение токенов использует кэш актёров сцены вместо полного обхода мира; запросы синхронизации объединяются последовательно.
- [x] Укреплённая душа уменьшает окончательный пакет урона заклинания Midi-QOL без повторного уменьшения уже применённого сопротивления.
- [x] У призывов есть штатные активности атаки, спасброска, лечения и защиты. Исправлены дальность Духа жизни, запрещённые типы целей, физические сопротивления фамильяров и современное поле чувств.
- [x] Дух защиты уменьшает следующий пакет до фактически предотвращённого урона; самоурон подтверждается событием применения. Дух жизни получает 14 урона после обработки лечения. Взаимодействие с живой damage-card ещё проверять.
- [x] Повторный спасбросок Ужасающей старости снимает эффект при успехе. Иммунитет состоянию предотвращает наложение; перевод боя назад не запускает turn-end повторно.
- [x] Вихрь создаёт через GM шаблон и штатную минутную концентрацию. Подтверждённый провал возвращает расход; потеря концентрации или окончание минуты удаляет шаблон. Указатель Освящения существует 6 секунд игрового времени; временные хиты союзникам подтверждаются через GM и не заменяют более высокий запас.
- [x] Проверены выдача трансформаций на уровнях 1/6/11/16, один бонус текущего/предыдущих уровней и обязательный недостаток. Подстановка посторонней особенности в окно выбора отключена для новых карточек.
- [x] Проверены привязки подклассов и ссылки выдаваемых особенностей. Валидатор и тесты проверяют реальные функции зарегистрированных действий и Midi callbacks, а не наличие названий в тексте.
- [x] Добавлен read-only API inspectAutomation(actorOrUuid): эффекты, сроки, зависимости, ресурсы, незавершённые призывы и причины недоступности.

## Безопасное обновление

Полностью перезапустите Foundry и мир, а не только браузер: сервер должен загрузить manifest с socket: true.

Диагностика выбранного токена в консоли:

```js
await game.modules.get("the-grimoire-of-grimgutz").api.inspectAutomation(canvas.tokens.controlled[0].actor)
```

В items[].migration видны конфликтующие поля. Для старой карточки без снимка модуль не может доказать отсутствие ручной правки: обновление согласует GM, сохраняя выбранные особенности и потраченные ресурсы. Определения Advancement не заменяются автоматически. Старые уникальные союзники без снимка сохраняются и отмечаются в отчёте.

Связанные токены по правилам Foundry разделяют лист, хиты и эффекты актёра; для полностью независимых экземпляров нужны несвязанные токены.

## Границы автоматизации

- Смерть выбранного существа в последнюю минуту и CR для духа странника подтверждает Мастер.
- Магическое обнаружение Полого, пространственные ограничения Поглощения и условные свойства духов подтверждаются.
- Разрушение имеет штатный спасбросок Мудрости и половину урона при успехе; число к6 за прожитые раунды, максимум восемь, и момент исчезновения подтверждаются.
- Спасброски и повторный урон Вихря, неоднозначное мировоззрение, нестандартная ячейка Освящения и очищение земли остаются подтверждаемыми.
- Готовый шаблон Шикигами не выдумывает урон выбранного зверя: точную форму и её атаку настраивает GM.

## Игровой чеклист — не выполнен локальными тестами

- [ ] Игрок без права создавать актёров: призвать группу на своей сцене, пока активный GM смотрит другую; второй GM не создаёт дубликаты.
- [ ] Отменить каждый диалог до расхода. Проверить частичный провал, поздний ответ и смену активного GM при pending; не возвращать ресурс по одному тайм-ауту.
- [ ] На связанном и несвязанном токенах включить ауру, продвинуть время на 60 секунд, восстановить ресурс и включить снова. Сохранить неизменённую форму в середине срока — без продления.
- [ ] Проверить turnEnd/sourceEnd на нужном ходе, подавление эффектов и перевод боя назад.
- [ ] Проверить маленькие/большие и скрытые токены, разные единицы и диагональные правила, уход из зоны и переключение GM между сценами.
- [ ] Обновить уровень союзника: сохранить раны, расходы, ручные значения и 0 хитов. Сменить форму — без второго актёра.
- [ ] Потерять концентрацию Ритуалиста: духи враждебны, не удаляются. Вернуть контроль, изгнать; проверить десять минут и 0 хитов.
- [ ] Проверить штатные активности духов с Midi-QOL: уже имеющееся сопротивление, healing/tempHP, защита до применения и самоурон после подтверждения damage-card.
- [ ] Проверить живое окно Advancement на 1/6/11/16, выбор старого бонуса и обязательный недостаток. Старые конфликты не перезаписывать автоматически.
- [ ] Изменить описание, активность, числовой эффект и его имя вручную; перезагрузить мир и убедиться, что правки сохранены.

Игровые сценарии этой проверкой не выполнены. Проверены локальные сценарии и сигнатуры установленного D&D5e 5.3.3 / Midi-QOL 14.0.9; это не заменяет игровые проверки. Пересборка библиотек выполняется только после освобождения их миром Foundry.

## Проверки и коммиты

Для скриптов используется npm run verify; после изменений карточек — npm run check с пересборкой библиотек. Служебные LOG и LOG.old не коммитятся; числовые .log являются данными LevelDB и входят в обновлённые библиотеки. Публичные методы сохранены. Работа разбита на небольшие коммиты; push выполняется только отдельным запросом.
