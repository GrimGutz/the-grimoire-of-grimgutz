# Фабрика

Источник: `Transformation_Factory.pdf`, печатные страницы 32–37 и продолжение. Все семь страниц сверены визуально: PDF сканированный. Это трансформация, не престиж-класс.

Основная карточка: **Игроку → Трансформации → Трансформация: Фабрика**. В **Мастеру → Особенности → Фабрика** находятся 14 бонусов, четыре недостатка, 51 справочное улучшение в четырёх областях и восемь материалов гомункула. В основной библиотеке трансформаций остаётся только входная карточка.

## Развитие и установка

Требование INT 13 проверяется только при включённой строгой проверке требований. Уровни персонажа 1/6/11/16 открывают ступени I/II/III/IV. На I выдаются оба бонуса и недостаток; дальше — недостаток и один ещё не выбранный доступный бонус текущей либо предыдущих ступеней. Зависимости «Оно живое → Изменение с модификацией → Машина бессмертна!» не обходятся перетаскиванием карточки. Сл = 8 + БМ + ступень + INT создателя.

1. На «Изготовленной форме» выберите STR/DEX и тип тела. Числовые эффекты ограничены 16 этим способом и не снижают уже высокую характеристику.
2. Завершите нативный короткий отдых. Через «Фабрику инноваций» выберите согласного получателя, новую установку/замену, область и улучшение. GM подтверждает компоненты и физическую доступность операции.
3. Проверяются доступность бонуса, отсутствие дубликата и занятость слотов всеми создателями. Только после подтверждения расходуются 100/200 зм, появляется собственная установленная карточка, применяются нужные эффекты и отмечается операция этого SR. Другие монеты автоматически не размениваются.

На себе: голова 1, тело 3, руки/ноги по 2; Deus добавляет по одному слоту **только себе**. У другого существа сначала один общий слот; Скульптор плоти открывает ему обычные четыре области. Справочная карточка сама ничего не устанавливает. Демонтаж через кнопку GM не возвращает золото и не сбрасывает Зависимость. Ручные правки карточек не перезаписываются: изменённая старая карточка может оставаться для проверки, но без записи установки не даёт бонуса.

## Что обрабатывается автоматически

- Реальные параметры формы, максимума HP, сопротивления и иммунитеты. Установленные чувства, инициатива, выбранный спасбросок, броня, скорости, концентрация, характеристики и их максимумы. Для текста и владений пустые эффекты не создаются.
- Зависимость после первой реальной операции: 72 часа, с Отвыканием 24 часа; психическая уязвимость, запрет концентрации и условные помехи. Отдых сам по себе её не снимает.
- Подтверждённое критическое повреждение: минутное отключение **всех установленных улучшений** данного создателя, включая Скульптора и Deus. Карточки и их расход сохраняются. INT в конце хода использует сохранённую Сл; успех либо истечение минуты возвращает улучшения. Повторный callback не продлевает срок.
- Живой материал: начало хода, не выше половины максимума, никогда при 0 HP. Стойкость: после подходящего урона до 0 предлагается CON, без излучения и критов.
- Электрическая дуга после рукопашного попадания предлагается владельцу; цепочка разных целей проверяется по 10 футов, дополнительные цели совершают DEX. Перезарядка к6 на 6 — в начале своего хода. Заземление использует реакцию после согласия и подтверждённый окончательный электрический урон; смешанный неразделимый пакет требует решения GM. Отражение не запускает себя заново.
- Укус и Клинки богомола — настоящие атаки; типизированные добавки яда/электричества, Кулаки гориллы и явно определённые атаки Силой проходят через Midi. При сочетании Берсерка и Рефлексов — преимущество первой атаки своего хода, не бесплатный повтор отменённого расхода.
- Второе сердце: действие, половина максимума, **одно применение за LR**, по уточнению пользователя. Брандмауэр/Иммунизатор предлагают расход после подходящего провала; Гипермобильность — реакцию до DEX с половиной урона. Преимущества не распространяются на все CON/DEX подряд.
- Биомонитор предлагает имеющееся зелье с настоящей лечащей активностью при пересечении половины HP; не создаёт зелье и не применяет его без согласия.
- Интеллект-привод выбирает реально доступную дополнительную ячейку, включая pact, и усиливает конкретное заклинание. Повторный callback не тратит её ещё раз. Отмена до подготовки урона возвращает только однозначно подтверждённый неизменённый расход; неизвестный исход требует проверки.
- Ослабление магии: только подходящие заклинания в поддержанном бою, к6 раз за ход, на 5–6 исключение цели; блокировка после успеха до начала собственного хода. Совершенство уменьшает физический урон только немагических атак, без повторного сопротивления.
- Вознесение: нативное действие, часовая защита/полёт, возвращение при 0 HP/завершении; срок повторного использования бросается один раз и считается в **1к6 реальных LR**, не днях. Перенос сознания — отдельные семь игровых дней.

Для Катапульты, Доминирования, Невидимости, Ускорения и заклинаний Вознесения нужны **собственные нативные карточки заклинаний** на владельце. Используются их реальные эффекты и концентрация без расхода ячейки; отдельные применения улучшения расходуются штатно. Отсутствующая карточка вызывает понятное предупреждение, не фиктивный успех. У Сандевестана GM проверяет отсутствие стороннего макроса вялости и разрешает полное дополнительное действие.

## Гомункулы

После LR выбирается один новый гомункул из доступного материала: глина, дерево, плоть, камень; позже железо/кристалл, затем адамантин/мифрил. Нужны пять кубических футов материала и свободное место. Создаётся настоящий NPC с токеном и нативным Дроблением. Денежная цена, концентрация, срок существования и общий лимит спутников не выдумываются. Повторная операция требует нового LR; старый спутник не удаляется и не лечится созданием нового. Есть отдельное подтверждаемое удаление собственного NPC.

КД, HP, атака БМ + ступень, урон 1к12 + ступень и материалы заданы явно. Напечатанное среднее «13» не соответствует формуле: используется формула. Управляемые характеристики обновляются по уровню создателя, сохраняя дефицит HP, нулевые HP, потраченные применения и ручные изменения. Для несвязанных токенов сначала обновляются индивидуальные дельты, затем мировой шаблон.

Дерево: настоящий размещаемый залп с DEX. Камень: выбранные видимые цели, WIS, минута замедления/запрета реакций и повторные спасброски. Железо/форма энергии: ответ после рукопашного попадания, прямое касание железа подтверждает GM. Кристалл: отражение окончательного лучистого урона без рекурсии. Адамантин: защита от критов. Мифрил: скорость, подходящее Уклонение и Ослабление магии. Глина: временный размер и добавка Дробления; увеличение клеток токена и досягаемость контролирует GM. Плоть: напоминание о дополнительной атаке после электричества, саму атаку выполняет владелец.

## Что намеренно остаётся вручную

Согласие, компоненты, видимость, сюжетная внешность, узкие иммунитеты по УС, смерть/анабиоз тела и смена плоскости. Контроль гомункулов, инициатива, перемещение и число атак; допустимость лечения деревянного конструкта, если система его запрещает.

Улучшения с ручным контекстом имеют явные примечания на справочной **и установленной** карточках: бесшумная Скрытность, дыхание, перенос тяжестей, прыжки, падение, принудительное перемещение, инструменты, loading, досягаемость, дополнительные руки, отслеживание угроз после отчёта, отдельные CON двух концентраций. Кровотечение ссылается на внешний Grim Hollow, которого нет в этом PDF. Для Амортизаторов силы не выдуманы срок/нижний предел STR; для Инерции — момент расхода бонуса. У Силовых топтунов круг/STR/урон нативные, но отбрасывание, влияние трудной земли и её неизвестный срок задаёт GM.

## Проверка

`tests/factory.test.mjs`, общий `tests/progression.test.mjs`, регистрационные проверки и валидатор библиотек. Сценарии вне открытой сцены сохраняются в GM-очередь; активен только один GM. Это проверки кода с моделями документов, **не утверждение о проведённой живой игре** с двумя GM. История неизвестных исходов остаётся в диагностике; они не повторяются автоматически.
