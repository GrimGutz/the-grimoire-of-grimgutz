# Автоматон

Источник: `Transformation_Automaton.pdf`, печатные страницы 27–30 (четыре страницы PDF). Основная карточка находится в «Игроку → Трансформации»; 14 бонусов и четыре недостатка — отдельные карточки в технических особенностях. Используются штатные иконки Foundry.

## Добавление и развитие

Перетащите **Трансформация: Автоматон** на персонажа. Требование — Сила 13; его проверка, как у остального контента, включается настройкой модуля, а не действует принудительно по умолчанию. СЛ равна `8 + БМ + модификатор Силы`, без добавления ступени трансформации.

Штатный Advancement на уровнях персонажа 1/6/11/16 выдаёт:

- I: Модель Автоматона, Форма Конструкта и Восприимчивость к Анти-Магии.
- II–IV: обязательный недостаток этой ступени и один ещё не полученный бонус текущей или любой предыдущей открытой ступени. «Дополнительные бонусы» PDF участвуют в том же выборе, не выдаются бесплатно.

В «Модели Автоматона» выберите одну модель. Изменение уже выбранной модели подтверждает GM. Временное снижение уровня блокирует более высокие бонусы, а выбор старого бонуса не снижает ступень: её определяет также обязательный недостаток.

## Что делает модуль

| Способность | Реализация |
| --- | --- |
| Форма Конструкта | Реальные эффекты Силы +2 / Телосложения +1 с пределом 16; тип Конструкт. Уже более высокие значения не понижаются. |
| Проворная модель | +10 футов ходьбы (3 м при метрической скорости), бонус спасбросков Ловкости по ступени. |
| Модель воина | Условное преимущество атак через Midi при живом союзном токене в 5 футах; бонус урона по ступени только активностям атаки. Нейтральное отношение не угадывается. |
| Модель джаггернаута | Плоский КД 19 и бонус спасбросков Телосложения по ступени. |
| Бронебойный | Бонус максимума хитов по общему уровню персонажа; без бесплатного лечения. |
| Механизированный полет | Повышение полёта до скорости ходьбы, без уменьшения более высокого полёта. |
| Бастион | Действие включения, бонусное действие завершения, нулевые скорости. Общий окончательный Midi-пакет до `5 × ступень` включительно обнуляется. |
| Сила и уверенность стали | Перед входящим Midi-уроном — предложение реакции за использование, бросок `(ступень − 1)к12 + Сила`. Уменьшается общая сумма, не каждый тип отдельно. Запас БМ, LR — согласованное правило. |
| Плоть слаба! | Необязательное уменьшение общей суммы на 4 перед Midi-применением. |
| Живой материал | До 10 хитов в начале хода, только при положительных хитах и не выше половины эффективного максимума. Снимок боя берётся до асинхронных операций; пропущенное событие другой сцены попадает в очередь GM. |
| Перегрузка | Одно использование до SR/LR; отдельная электрическая часть урона рукопашных атак до начала следующего хода. Дополнительным действием распоряжается игрок. Вне боя эффект заканчивает GM. |
| Встроенное оружие | Выбор одного собственного предмета после подтверждённого LR. Дополнительная кость и дальность только выбранного оружия, исходный предмет не переписывается. Необычные/пользовательские формулы костей проверяются GM. |
| Встроенный щит | Выбор атакующего, подтверждение окончательного урона и его типа GM; нативная реакция, спасбросок Ловкости, половина полученного урона при провале. |
| Встроенный посох/палочка | Один/два независимых осколка на III/IV ступени с выбором всех целей до расхода одного действия. Заряды до пяти и разрядка линией 60 × 5 футов со спасброском. Частичный/неизвестный результат не повторяется автоматически. |
| Сопротивление заклинаниям | Проворная: преимущество только от заклинаний и явно помеченных магических источников. Джаггернаут: сопротивление только урону заклинаний, без повторного деления. Воин: три выбранных заклинания, новый выбор после LR, исключение цели из конкретного Midi-потока до спасбросков/эффектов. Подавление/выключение эффекта прекращает защиту. |
| Дуговая батарея | Подтверждённая GM загрузка одной карточки с исходными параметрами и уровнем. Вместимость по сумме уровней; выпуск нативной активностью за действие, без новой ячейки. Карточка блокируется до подтверждения результата; отмена сохраняет запас, неизвестный результат требует проверки. Использованные служебные карточки сохраняются для разрешения UUID текущих workflows; напрямую использовать их нельзя. |
| Реактивные катушки | Выбор элемента. Предложение временных хитов после подтверждённого урона, без сложения; часть смешанного урона уточняет GM. Бонус одному рукопашному попаданию резервируется до применения и списывает `2 × модификатор Телосложения` временных хитов только после подтверждения. GM согласует тип урона; при спорном типе — вручную. Отмена освобождает резерв. Если запас изменился к применению, результат требует проверки, а не отрицательных хитов/повторного бонуса. |
| Антимагия | Подтверждаемые вход/выход; отдельное Замедление либо потеря сознания на IV ступени. Выход снимает только собственное состояние. Отдельная кнопка бросает нужные к8/к12 от Рассеивания магии. |
| Перезарядка / Высасывание силы | Отметка времени, интервалы 10/8 часов и подтверждённое GM начисление одного истощения. Без автоматического наказания за перемотку времени. LR отмечает начало нового отсчёта. |
| Нестабильное ядро | Согласие владельца и GM; круг 200 футов, спасбросок Ловкости и 20к8 силового урона, половина при успехе. Фиксируется время восстановления, без автоматической смерти/удаления предметов. |

## Намеренно вручную и неоднозначности

Иммунитет к изменению формы и особый четырёхчасовой покой — GM: произвольные способности других модулей нельзя безопасно распознать по названию. Для Замедления числовые штрафы автоматизированы; запрет реакций, ограничение действий/атак и задержка заклинаний проверяются GM. Мир не сканируется на наличие антимагического поля.

Минутный ремонт Бронебойного — трата штатной кости хитов на листе после подтверждённой минуты. Это не полноценный короткий отдых и не повод восстанавливать все ресурсы. Короткий отдых на час дольше учитывает GM при продвижении игрового времени.

PDF не задаёт тип урона Рассеивания магии, способ загрузки батареи и урон при успешном спасброске разрядки посоха. Тип ответного урона щита и катушек требует согласования. Для линии посоха по умолчанию нет урона при успехе; нестандартный конус 60 футов с конечной шириной 15 футов — отдельный шаблон GM, не подмена стандартным конусом Foundry. Исходные специальные бонусы/скрипты сторонних заклинаний при загрузке батареи проверяет GM; чужие макросы не копируются.

Смерть от взрыва, уничтожение предметов, решение о точном моменте возвращения с 1 хитом после восьмичасовой стабилизации и перестройки тела остаются GM. Автоматического воскрешения актёра, очистки инвентаря и удаления чужих документов нет.

## Проверки

Поведенческие проверки: `tests/automaton.test.mjs`; общие границы Advancement — `tests/progression.test.mjs`. Проверяются отказы, повторные callbacks, пороги хитов/урона, подавленные эффекты, расход реакции, разные сцены, союзники, батарея и временные хиты. Диагностика — поле `automaton` в `inspectAutomation()`.

Проверки в Node не заменяют живую проверку Foundry с игроком, двумя GM, несвязанными токенами и конкретными настройками применения урона Midi-QOL.
