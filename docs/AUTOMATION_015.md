# Автоматизация 0.15.0

Реализованы восемь направлений. Локальные поведенческие проверки и сверка сигнатур установленного D&D5e 5.3.3 / Midi-QOL 14.0.9 не заменяют проверку живого игрового сеанса.

## Использование

- Стратагемы: нажмите карточку, выберите цели и подтвердите условия. Отмена первоначального выбора не расходует действие/ресурс. Перемещение выполняется игроком; уже сыгранное перемещение не откатывается при поздней отмене.
- Присутствия: выберите получателей кнопкой карточки. Выбор сохраняется отдельно для каждой сцены. Общего радиуса нет; зрение, слух, стены и невидимость получателей намеренно не проверяются. Недееспособность Лидера отключает присутствие.
- Необязательные реакции, Кровопускание, начало высасывания и антимагия предлагают выбор владельцу. Условия, которые нельзя определить достоверно, подтверждаются явно.
- Панель: настройки мира → «Гримуар» → «Панель автоматизации». В листах персонажей также добавлен пункт панели. Пользователь видит только доступные ему документы.
- Очередь: активный GM открывает указанную сцену и выбирает «Провести» или «Пропустить». «Нужна проверка» не даёт повторного применения: проверьте сыгранную карточку и расход вручную.

## Подключённые правила

| Направление | Реализованное поведение |
| --- | --- |
| Нематериальный вихрь | В конце хода цели внутри неподвижной области: Ловкость, при провале 8к8 выбранного типа. Без повторного расхода Гнева/действия. Концентрация и срок прекращают новые события; движение не наносит урон. |
| 17 стратагем | Выбор целей/проверок/оружия, временные хиты, scoped-бонусы, общий запас усиленных попаданий, реакции, сроки, масштабирование дистанций. Рывок и прыжок показаны в панели, путь задаёт игрок. Нестандартные проверки выхода из захвата подтверждает GM. |
| 6 присутствий | Постоянные бонусы и событийные части, сильнейший бонус одного вида, без дублирования собственной скорости. Отвлекающее требует доступной реакции, но не расходует её и не запускает само себя повторно. |
| Кровопускание | Связь с конкретным Кровавым заклинанием; после согласия 2 крови, Телосложение и 2к8 некротического урона. В конце хода повторный спасбросок/урон; успех снимает кровотечение. Наличие крови подтверждает GM. |
| Высасывание крови | Штатный укус/урон, подтверждённая допустимость цели, связь в 5 футах, одно высасывание в раунд. Лечение половины окончательного подтверждённого урона; без лечения при отмене или повторном callback. Тип не задан исходником и выбирается GM. |
| Метка / Шевелящаяся броня | Отдельные лимиты отметок и особых атак; условная помеха и добровольная ответная атака. Броня меняет КД только конкретной атаки или даёт преимущество подходящему спасброску. Связанный рой уничтожается только после подтверждённого использования; умный рой не затрагивается. |
| Антимагия Полого | Выжигание: 6 зарядов, спасбросок, к6 и выбор ячеек, включая договорные. Ослабление: дополнительный расход и минутный эффект конкретной цели. Рассеивание: реакция, стоимость по уровню, GM подтверждает аннулирование без автоматического возврата чужой ячейки. Запас NPC не раскрывается игрокам. |
| Панель и очередь | Ауры, области, призывы, присутствия, ограниченные бонусы, сроки и причины недоступности; GM-only очередь с сохранёнными параметрами. Неизвестный результат и прерванное выполнение не повторяются автоматически. |

## API и расширение

```js
const api = game.modules.get("the-grimoire-of-grimgutz").api;
await api.openAutomationPanel(canvas.tokens.controlled[0]?.actor);
await api.inspectAutomation(canvas.tokens.controlled[0].actor); // только чтение
await api.resolvePendingAutomation("event-id", "apply"); // активный GM
```

Существующие публичные методы сохранены. Конфигурация документов остаётся версии 1. Правила задаются явно в `area-definitions`, `leader-presence-definitions` и обработчиках доменов, не извлекаются из описаний. Состояния событий/ограниченных бонусов имеют версию 1 и конкретные UUID источника, цели, применения и сцены.

Журнал событий — GM-only JournalEntry. Подтверждения урона также сохраняются на карточке применения: перезагрузка GM и очистка старой истории не повторяют лечение/расход. Если урон применял другой GM либо владелец, результат передаётся активному GM с проверкой корреляции и текущего состояния, без передачи числовых хитов скрытого NPC. Логический тайм-аут не означает провал или разрешение на возврат ресурса.

Старые конфликты описаний/активностей/Advancement не перезаписываются молча. Проверьте `inspectAutomation().items[].migration`, если старая карточка не получила новую активность. Вне поддержанного потока Midi или при нестандартной формуле/типе урона требуется решение GM.

## Приёмочная проверка в Foundry

Следующие пункты ещё требуют живого сеанса; локальные проверки их взаимодействий выполняются отдельно:

- [ ] Игрок без права изменения чужих актёров; отказ от реакции/выбора, пустой ресурс, иммунитет и подавленный эффект.
- [ ] Два GM, разные открытые сцены, очередь после перезагрузки, скрытый источник и несвязанный токен.
- [ ] Вихрь: начальное применение, конец хода, движение без урона, потеря концентрации и окончание минуты.
- [ ] Направить атаку: общий запас нескольких союзников, последующие попадания, отмена/ручное применение damage-card.
- [ ] Присутствия: отсутствие двойной скорости, лечение/временные хиты, критическое попадание и убийство в одном workflow, отсутствие цепочки Отвлекающего.
- [ ] Кровопускание: конкретный Кровавый cast, повторный урон, успех повторного спасброска, отсутствие второго обработчика.
- [ ] Высасывание: конечный урон после сопротивления/иммунитета, отмена, повторный callback, разрыв дистанции и смерть источника.
- [ ] Метка/броня: помеха только по другой цели, границы досягаемости, одна реакция и связанный рой.
- [ ] Полый: обычные/договорные ячейки, частичная потеря, более высокая ячейка, уже потраченная ячейка аннулированного заклинания.

Для скриптов: `npm run verify`. Перед сборкой закрытого мира: `node tools/check-local-packs.mjs` проверяет отсутствие сторонних изменений содержимого библиотек относительно Git HEAD. Затем `npm run check`. Служебные LOG/LOG.old не коммитятся; числовые .log содержат данные. Push — отдельно.
